The shader implements the full forward pipeline: AP0 glow, geometric hue and cubic red modifier, AP0→AP1 conversion and clamp, RRT desaturation, segmented quadratic B-spline RRT tonescale, segmented ODT tonescale, cinema white/black scaling, dark-to-dim surround compensation, ODT desaturation, XYZ / Bradford D60→D65 adaptation, Rec.709 conversion, and display-gamut clipping.

Input is scene-linear ACES2065-1 / AP0, with middle gray at 0.18. Output is linear Rec.709 / D65, where display white is 1. The original ODT's final sRGB encoding is performed by the common workbench output stage. It does not use a five-coefficient ACES approximation. The back-to-back AP1→AP0 and AP0→AP1 matrix conversions are algebraically cancelled. Geometric hue for exact neutrals is safely assigned zero; saturation is zero there, so the red modifier is unchanged.

This entry is the **fixed SDR 100nit, dim surround preset**. Workbench HDR presentation can show it, but HDR headroom does not scale the transform. It is not labelled as a 1000nit ACES output transform. This preserves the upstream preset, rather than modifying its reference behavior. The separate ACES 2 entry supports a variable peak luminance.

Independent reference vectors are tracked in `references/validation/aces_reference_vectors.json` and regenerated by `generate_aces_ocio_vectors.py` with the official ASWF **PyOpenColorIO 2.6.0** CPU implementation, builtin `ACES-OUTPUT - ACES2065-1_to_CIE-XYZ-D65 - SDR-VIDEO_1.0`, followed by XYZ D65 → Rec.709 and the ODT's clipping. Its 33 inputs cover neutrals, AP0 primaries / secondaries, colored HDR highlights, and negatives. Inputs are quantized to float16 before evaluating the oracle, matching the workbench source texture. Shader parsing and numerical GPU comparisons use the project's reference validation suite; f32 and half output rounding are accounted for. This oracle is independent of the WGSL port and is not the previously attempted native CTL evaluator.

All 33 ACES 1.3 vectors passed in the actual RTX 4090 / Vulkan runtime, together with 165 ACES 2 vectors, using `cargo +stable test --locked reference_aces_ports -- --ignored --nocapture`. The test also verifies that enabling HDR presentation leaves this fixed SDR reference unchanged.
